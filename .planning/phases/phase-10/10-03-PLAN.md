<objective>補齊英文介面：集中的翻譯字典、結構圖標籤、資料名稱、表單與通知。</objective>

<context>
## 1. 翻譯字典：`assets/scripts/i18n.js`（新檔）
```js
// I18N.t('toolbar.reference') → 依目前語言回傳文字；支援 {name} 參數：I18N.t('list.emptySystem', { system: '眼睛' })
// I18N.lang() → 'zh' | 'en'（讀取 utils.js 既有的 getCurrentLanguage，不要另外存一份狀態）
```
- 字典為 `{ zh: {...}, en: {...} }`，key 依區域分組（`toolbar.*`、`list.*`、`form.*`、`body.*`、`eye.*`、`teeth.*`、`notify.*`、`time.*`）。10-01 context 列出的介面文字都要有 key。
- 缺 key 時回傳 key 本身並 `console.warn`（開發時容易發現），不要拋錯。
- 載入順序：在 utils.js 之後、其他模組之前。

## 2. 結構圖
- `odontogram.js`、`eye-diagram.js`、`body-map.js` 的 `render` 新增 `labels` 選項（象限、方向、視圖名稱等），預設沿用目前的中文，app 以 `I18N.t()` 傳入。
- 名稱：英文模式時，牙齒用 `tooth-numbering.json` 的 `name`（乳牙在 odontogram.js 補英文名稱，例如 `Upper Right Primary Second Molar`）、眼睛用 `nameEn`、身體用 `body-systems.json` 的 `nameEn`。aria-label 也要跟著語言。
- app 監聽既有的 `language:changed` 事件（utils.js 的 `updateLanguageUI` 會發出）：重新渲染目前系統的結構圖並保留選取狀態、縮放狀態與病歷標示。

## 3. 表單與模態
- `disease-form.js`：`updateLanguageDisplay` 用了 `this.currentLanguage`，但這個值沒有在語言切換時更新（Claude 審查時確認英文模式下表單仍是中文）。改用 `I18N.lang()`；疾病清單的 label 在英文模式顯示 `nameEn`（沒有 nameEn 就顯示 name）。
- `body-operation-form.js`：已有 `name_en` 的操作類型改用它；「側邊：」、左／中／右、操作類型、操作描述、醫生備註等標籤改用 `I18N.t()`。
- 模態中的位置資訊（牙齒名稱＋FDI、眼睛結構＋眼別徽章、身體部位＋側別）、「結構類型:」都要翻譯。**儲存到病歷的 `locationName` 維持中文**（病歷資料格式不變，清單顯示與歷史記錄一致）。
- 通知訊息（儲存成功、參考圖提示、備份還原結果等）改用 `I18N.t()`。先 `grep -rn "showNotification(" assets/scripts` 列出所有呼叫點逐一處理。

## 4. 清單
空狀態訊息、時間戳（移除 10-02 留下的 TODO，改用 `t('time.unknown')`）、側別徽章改用 `I18N.t()`；`.record-group` 內由病歷資料來的文字不翻譯。

## 5. 其他
新檔加入 index.html 與 sw.js；`bump_cache.py`；快照核對後 `--write`。
