## 牙齒座標映射系統

### 解剖基礎

#### 永久牙編號系統

**Universal Numbering System** (美國標準)
```
            1-8 (右上)    9-16 (左上)
            ──────────────────────
            |  8  7  6  5 | 4  3  2  1 |
     Right  |  8  7  6  5 | 4  3  2  1 | Left
            |──────────────────────────|
            | 24 23 22 21 | 20 19 18 17|
            ──────────────────────────
            25-32 (右下) 17-24 (左下)
```

- **右上** (#1-8): 磨牙→犬牙→門牙 (後←前)
- **左上** (#9-16): 門牙→犬牙→磨牙 (前→後)
- **左下** (#17-24): 磨牙→犬牙→門牙 (後←前)
- **右下** (#25-32): 門牙→犬牙→磨牙 (前→後)

**牙齒分類**:
- 門牙 (Incisors): 中門牙 (#8,9,24,25)、側門牙 (#7,10,23,26)
- 犬牙 (Canines): #6,11,22,27
- 第一前臼齒 (1st Premolars): #5,12,21,28
- 第二前臼齒 (2nd Premolars): #4,13,20,29
- 第一磨牙 (1st Molars): #3,14,19,30
- 第二磨牙 (2nd Molars): #2,15,18,31
- 第三磨牙 (3rd Molars/Wisdom): #1,16,17,32

#### 乳牙編號系統

**Universal Numbering System for Primary Teeth**
```
            A-E (右上)    F-J (左上)
            ──────────────────────
            |  E  D  C  B | A |
     Right  |  E  D  C  B | A | Left
            |──────────────────|
            | T  S  R  Q | P  |
            ──────────────────
            T-P (右下) K-O (左下)
```

- **右上** (A-E): E(磨牙) → D,C → B,A(門牙)
- **左上** (F-J): J(磨牙) → I,H → G,F(門牙)
- **左下** (K-O): O(磨牙) → N,M → L,K(門牙)
- **右下** (P-T): T(磨牙) → S,R → Q,P(門牙)

#### 點擊檢測算法

```javascript
function getToothAtPosition(x, y, type = 'permanent') {
  const teeth = DENTAL_COORDINATES[type];

  for (const [toothId, coord] of Object.entries(teeth)) {
    const distance = Math.sqrt(
      Math.pow(x - coord.x, 2) + Math.pow(y - coord.y, 2)
    );

    if (distance <= coord.radius) {
      return {
        success: true,
        toothId,
        ...coord,
        confidence: 1 - (distance / coord.radius) // 0-1 分數
      };
    }
  }

  return { success: false, message: "Not in tooth area" };
}
```

#### 精度要求

- **座標精度**: ±3px (高分辨率 2x)
- **半徑設定**: 根據牙齒大小，磨牙 24-28px, 門牙 18-22px
- **點擊容錯**: 容許超出半徑 20% 的誤點

### 數據同步策略

1. **自動保存**: 每次記錄提交後立即保存到 localStorage
2. **版本控制**: 在每個記錄中添加 `version` 字段，支持遷移
3. **備份機制**: 支持導出完整備份到本地文件
4. **衝突解決**:
   - 同一牙齒同一日期的相同診斷視為重複
   - 用戶可選擇覆蓋、合併或跳過

## 安全與隱私

### 數據安全

1. **客戶端加密** (可選):
   - 使用 TweetNaCl.js 加密敏感信息
   - 密鑰由用戶設置

2. **本地存儲**:
   - 所有數據存儲在瀏覽器 localStorage
   - 不上傳到服務器 (離線優先)
   - 用戶可隨時導出和備份

### 隱私保護

1. **匿名化**:
   - 患者 ID 可選，可使用匿名 ID
   - 醫生名字可選

2. **導出控制**:
   - 用戶完全控制何時導出
   - 支持選擇性導出 (特定牙齒、日期範圍)

3. **刪除機制**:
   - 支持刪除單個記錄
   - 支持清空所有數據
   - 永久刪除 (無恢復)

### HIPAA/GDPR 考慮

- ✅ 不存儲在第三方服務器
- ✅ 用戶擁有完整的數據控制權
- ✅ 支持數據導出 (可移植性)
- ✅ 支持完整刪除 (被遺忘權)
- ⚠️ 建議: 添加一層加密選項增強隱私

## 結論

本設計文檔提供了牙科結構化病歷輸入系統的完整技術架構。核心特性包括：

1. **精確的座標映射系統** - 支持 32 顆永久牙和 20 顆乳牙
2. **直觀的用戶交互** - 點擊牙齒即可輸入病歷
3. **結構化的數據存儲** - 支持多個時間點的追蹤
4. **標準化的導出** - 支持 FHIR、JSON、CSV 格式
5. **響應式設計** - 支持桌面、平板、手機
6. **離線優先** - 完整的本地存儲能力

實現這套系統將為牙科專業人員提供高效、標準化的病歷輸入工具。
