# Proposal: UI 布局重设与疾病可视化系统

**Change ID**: `refactor-ui-layout-disease-viz`
**Status**: Proposal
**Date**: 2025-12-31
**Author**: User Request

---

## 📋 概述 (Executive Summary)

本提案旨在重新设计医疗病歷系统的用户界面，以提高可用性和信息清晰度。主要改进包括：

1. **左侧牙齿系统分离** - 将永久齿和乳齿分为独立的标签页
2. **疾病可视化** - 在牙齿图表上显示疾病关联的连接线
3. **右侧面板简化** - 移除 OCR 上传功能，简化导出选项
4. **文本导出优化** - 改进导出格式，展示时间轴视图

---

## 🎯 目标

- **改进用户体验**: 清晰分离永久齿和乳齿系统
- **增强信息可视化**: 直观显示牙齿与疾病的关联关系
- **简化操作界面**: 移除不必要功能，降低认知负荷
- **优化数据导出**: 提供结构化、易读的文本格式报告

---

## 📐 变更范围

### 1. UI 布局重设
- **文件**: `index.html`
- **影响**: 左侧面板、系统标签页、右侧操作面板

### 2. 疾病可视化
- **文件**: `assets/scripts/main.js`, `assets/scripts/annotator.js`
- **影响**: 牙齿图表渲染、连接线绘制、疾病关联显示

### 3. 导出功能优化
- **文件**: `assets/scripts/record-manager.js`, `assets/scripts/main.js`
- **影响**: 文本导出格式、UI 按钮移除
