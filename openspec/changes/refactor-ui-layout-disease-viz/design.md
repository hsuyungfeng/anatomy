## 🎨 疾病可视化设计

### 连接线设计

**连接线特性**:
- 从牙齿圆心指向疾病标签
- 按疾病类型使用对应颜色
- 显示疾病中文名称
- 多疾病时合并显示

**颜色映射** (按疾病类型):
```javascript
{
  "K00": "#FF6B6B",  // 牙齒發育 - 紅色
  "K01": "#FF8E72",  // 埋伏牙 - 橙紅
  "K02": "#FFA500",  // 牙根龋齒 - 橙色
  "K03": "#FFD700",  // 硬組織疾病 - 金色
  "K04": "#FF69B4",  // 急性根尖 - 熱粉紅
  "K05": "#00CED1",  // 齒齦炎 - 深青色
  "K06": "#87CEEB",  // 齒齦腫大 - 淺藍
  "K08": "#8A2BE2"   // 其他疾患 - 藍紫
}
```

### 连接线实现方案

**使用 SVG overlay**:
```
Canvas Layer (牙齒圖表)
   ↓
SVG Overlay (疾病連線)
   ↓
Text Layer (疾病標籤)
```

**关键实现类**:
- `DiseaseConnectionRenderer` - 渲染连接线和标签
- `DiseaseVisualizationManager` - 管理所有可视化元素

## 🔧 技术方案

### 1. 永久齒/乳齒系统切换

**实现方式**: 在 `牙齒系統` 內部添加子標籤頁

```html
<nav class="teeth-sub-tabs">
  <button class="teeth-tab teeth-tab--active" data-teeth-type="permanent">
    永久齒
  </button>
  <button class="teeth-tab" data-teeth-type="primary">
    乳齒
  </button>
</nav>
```

**数据管理**:
- `currentTeethType` 状态变量
- `loadTeethSystem(type)` 方法
- 重用现有的 `anatomical-systems.json` 数据

### 2. 疾病连接线渲染

**实现流程**:
```
1. 獲取該牙齒的所有標註
   annotations = recordManager.getAnnotationsByLocation(toothId)

2. 構建疾病列表
   diseases = annotations.flatMap(a => a.diseases)

3. 計算連線座標
   startPoint = tooth.position
   endPoint = calculateLabelPosition(disease, diseases.length)

4. 使用 Canvas 或 SVG 繪製連線
   drawLine(startPoint, endPoint, disease.color)
   drawLabel(endPoint, disease.name)

5. 添加滑鼠交互
   on hover → 高亮該疾病的所有連線
   on click → 打開該牙齒的詳細信息
```

### 3. 右侧面板简化

**删除元素**:
- OCR 上传标签页（整个 UI 元素）
- 匯出 JSON 按钮

**保留元素**:
- 病歷列表（时间轴）
- 匯出文字 按钮
- 清空 按钮

**实现**:
- 从 `index.html` 删除 OCR 相关 HTML
- 从 `main.js` 删除 OCR 事件监听
- 删除 `export-json-btn` 相关代码

### 4. 文本导出优化

**新格式**:
```
醫療結構化病歷報告
========================

病歷 ID: a1b2c3d4-e5f6-...
患者 ID: P123456
創建時間: 2025-12-31 10:30:00

[治療時間軸]
========================

2025-12-31 14:30 - 左上第一門牙
  疾病: K02 牙根龋齒
  摘要: 初期龋齒，建議補綴
  ─────────────────

2025-12-31 14:00 - 右下第一臼齒
  疾病: K05 齒齦炎及牙周疾病
  摘要: 輕度牙齦炎，建議洗牙

[統計信息]
```

## 📊 数据流

### 牙齿系统切换流程
```
用戶點擊 「永久齒」標籤
   ↓
觸發 handleTeethTypeChange('permanent')
   ↓
更新 currentTeethType = 'permanent'
   ↓
重新加載系統圖像 loadSystemImage()
   ↓
清除舊的標註和連線
   ↓
重新渲染永久齒圖表 + 疾病連線
   ↓
更新右側病歷列表 (篩選該系統的記錄)
```

### 疾病可视化流程
```
保存新的標註
   ↓
更新 RecordManager 中的數據
   ↓
觸發 'annotation:added' 事件
   ↓
DiseaseVisualizationManager 監聽該事件
   ↓
獲取該牙齒的所有疾病
   ↓
計算連線和標籤位置
   ↓
在 SVG Layer 上渲染連線
   ↓
更新右側時間軸視圖
```

## ⚠️ 技术考量

### 1. 性能考量
- **问题**: 大量连接线可能影响渲染性能
- **方案**:
  - 使用虚拟滚动处理大量标注
  - 缓存连接线计算结果
  - 使用 `requestAnimationFrame` 优化重绘

### 2. 响应式设计
- **问题**: 小屏幕上连接线可能混乱
- **方案**:
  - 在移动端隐藏连接线
  - 改为列表视图
  - 使用自适应布局

### 3. 无障碍设计
- **问题**: 颜色只依赖可能不符合 WCAG
- **方案**:
  - 添加图案或线条样式区分
  - 提供 ARIA 标签
  - 支持键盘导航
