# 眼睛標籤配對工具使用指南 (Eye Label Mapping Guide)

## 🎯 工具概述

眼睛標籤配對工具是一個互動式網頁應用，用於將眼睛圖像 (3Deye.png) 中的18個英文標籤與圖像中的具體元素進行配對。

**工具 URL**: http://localhost:8000/eye-label-mapping-tool.html

## 🚀 使用步驟

### 步驟 1: 打開工具
在瀏覽器中訪問配對工具：
```
http://localhost:8000/eye-label-mapping-tool.html
```

### 步驟 2: 瞭解界面
- **左側**: 眼睛圖像，上面有17個藍色圓點標記，每個圓點代表一個英文標籤
- **右側**: 18個英文標籤的完整列表
- **上方**: 進度條顯示已配對的標籤數量

### 步驟 3: 開始配對
1. **點擊右側列表中的標籤** 或 **點擊圖像上的圓點**
2. **彈出編輯對話框**，包含以下字段：
   - **標籤在圖像中的位置**: 例如 "左眼上方"、"中央"、"右側"
   - **該標籤指向的眼睛結構**: 例如 "視網膜"、"眼球後部"
   - **對應的結構 ID**: 例如 "left-eye-retina"（可選）
   - **備註**: 任何額外的配對信息

3. **填寫信息後點擊「保存配對」**

### 步驟 4: 重複配對
- 依次配對所有18個英文標籤
- 進度條實時顯示配對進度
- 已配對的標籤會顯示 ✓ 標記

### 步驟 5: 導出結果
- 完成所有配對後，點擊「**匯出配對結果**」按鈕
- 系統會自動下載 JSON 文件
- 文件名格式: `eye-label-mapping-YYYY-MM-DD.json`

## 📝 配對信息填寫指南

### 標籤在圖像中的位置 (Position)

填寫標籤在圖像中的相對位置：

**橫向位置**:
- 左側 / 左眼區域
- 中央 / 中間
- 右側 / 右眼區域

**縱向位置**:
- 上方 / 上部
- 中方 / 中部
- 下方 / 下部

**範例**:
- "左眼上方"
- "右眼下方"
- "中央"
- "眼球內部"

### 該標籤指向的眼睛結構 (Points To)

描述英文標籤通過箭頭或線條指向的眼睛部分：

**範例**:
- "視網膜"
- "晶狀體"
- "虹膜中央"
- "眼球周圍肌肉"
- "眼球後部血管"

### 對應的結構 ID (Structure ID)

如果可能，指定系統中已定義的結構 ID：

**可用的 ID**（來自 eye-coordinates.json）:
- `left-eye` / `right-eye` - 整體眼球
- `left-eye-cornea` / `right-eye-cornea` - 角膜
- `left-eye-iris` / `right-eye-iris` - 虹膜
- `left-eye-lens` / `right-eye-lens` - 晶狀體
- `left-eye-retina` / `right-eye-retina` - 視網膜

**如果不確定，可留空**

### 備註 (Notes)

添加任何額外的配對信息，例如：
- "標籤可能指向左眼或右眼"
- "標籤箭頭方向指向眼球下方"
- "此結構在3D圖中不清晰"

## 🎨 交互功能詳解

### 標籤標記 (Label Markers)

圖像上的圓點標記：
- **藍色圓點**: 待配對的標籤
- **紅色圓點**: 當前編輯的標籤
- **懸停效果**: 圓點放大並發光，顯示標籤編號

### 進度追踪 (Progress Tracking)

頂部進度條實時顯示：
- 已配對的標籤數量 (例：已配對: 5 / 18)
- 配對完成百分比 (例：28%)
- 進度條長度對應完成度

### 狀態徽章 (Status Badge)

列表中每個標籤旁的徽章顯示：
- **⏳ 待配對**: 尚未填寫配對信息
- **✓ 已配對**: 已填寫配對信息

## 🔧 常見問題 (FAQ)

### Q1: 我不確定某個標籤指向哪個眼睛部分怎麼辦？

**A**: 您可以：
1. 根據標籤在圖像中的位置進行估計
2. 根據英文名稱進行推斷（例：Retina = 視網膜 = 眼球後部）
3. 暫時留空，稍後根據圖像配對信息補充

### Q2: 可以修改標籤的位置嗎？

**A**: 可以。重新點擊該標籤，編輯對話框中修改信息，然後保存。

### Q3: 如何確保配對的準確性？

**A**:
1. 參考眼睛解剖學知識
2. 觀察圖像中標籤指向的方向
3. 與眼睛座標映射數據比對 (eye-coordinates.json)

### Q4: 導出的JSON文件可以用在哪裡？

**A**: 導出的文件可以：
1. 用於數據分析和統計
2. 集成到眼睛標籤映射系統
3. 作為配對結果的備份
4. 供後續開發和優化參考

### Q5: 可以重新開始配對嗎？

**A**: 可以。刷新頁面會重置所有配對（已配對的數據會清除，除非已導出）。

## 📊 最佳實踐

### 配對工作流

1. **第一遍掃描**: 快速查看所有標籤位置，獲得整體印象
2. **逐一配對**: 按編號依次填寫每個標籤的信息
3. **交叉驗證**: 完成後重新檢查每個配對是否合理
4. **導出備份**: 完成後立即導出結果

### 質量控制

- ✓ 檢查所有標籤是否都已配對
- ✓ 驗證位置描述是否清晰明確
- ✓ 確認指向結構的描述準確
- ✓ 檢查備註是否有助於理解

### 文檔記錄

建議在完成配對後：
1. 保存導出的JSON文件
2. 記錄配對的日期和時間
3. 標註任何不確定或需要驗證的項目
4. 包含配對人員和審核人員的信息
