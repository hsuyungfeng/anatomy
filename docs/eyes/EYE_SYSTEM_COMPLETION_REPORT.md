## 🔧 技術實現細節

### 4.1 核心組件集成

**應用主程序** (`assets/scripts/main.js`):
```javascript
// 眼睛標籤映射器初始化
this.eyeLabelMapper = new EyeLabelMapper({ debug: true });

// 眼睛系統加載時自動繪製標籤
if (systemId === 'eye' && this.eyeLabelMapper) {
  this.eyeLabelMapper.drawLabels(canvas, {
    showText: true,
    textColor: '#333',
    fontSize: 13,
    backgroundColor: 'rgba(255, 255, 255, 0.85)',
    borderColor: '#0066cc',
    borderRadius: 4
  });
}
```

### 4.2 標籤點擊檢測

**實現位置**: `assets/scripts/main.js` (行 815-844)

流程:
1. 用戶點擊眼睛圖像
2. 系統檢測點擊位置是否在標籤範圍內（40px 容差）
3. 若擊中標籤，優先使用標籤的結構 ID
4. 否則使用眼睛座標映射進行結構檢測
5. 打開疾病記錄表單

## 📞 支持與反饋

### 常見問題

**Q: 如何自定義標籤位置？**
A: 編輯 `data/eye-label-mappings.json` 中的 position 欄位，或使用 `setLabelPosition()` 方法。

**Q: 如何添加新的眼科疾病？**
A: 編輯 `data/disease-categories.json`，在 eye 系統的 diseases 陣列中添加新疾病。

**Q: 標籤不顯示怎麼辦？**
A: 檢查瀏覽器控制台的錯誤信息，確認眼睛系統已正確加載。
