# 眼睛图像文字识别 (Eye Image Text Recognition)

## 任务说明
从 3Deye.png 图像中识别所有英文文字和字母，建立文字与图像元素的映射表。

## 识别方法
1. 逐个识别图像中的英文文字和字母标签
2. 记录文字的位置（左/中/右，上/中/下）
3. 记录文字的指向方向（箭头或线条指向的方向）
4. 建立文字-位置映射表
5. 等待用户将文字与实际眼睛元素配对

## 识别挑战

由于图像分辨率和大小的限制，以下因素影响了文字识别的准确性：

1. **图像分辨率**: 3Deye.png 尺寸为 1313x664 像素，但文字标签相对较小
2. **文字大小**: 图像中的英文文字标签非常小，难以清晰读取
3. **文字清晰度**: 图像压缩可能导致文字模糊
4. **文字方向**: 某些文字可能有倾斜或旋转
