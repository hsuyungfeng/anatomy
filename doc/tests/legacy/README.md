# 舊版手動測試腳本 (Legacy Tests)

本目錄存放專案歷史開發期間撰寫的手動 Playwright 測試腳本（`test-*.py`）。

## 注意事項

- **不在 `run_all.py` 測試集合內**：這些腳本為手動除錯輔助腳本，不納入自動化回歸測試流程。
- **執行前準備**：
  - 腳本內部寫死了本機測試伺服器位址（通常為 `http://localhost:9000` 或 `http://localhost:8080`），執行前請自行於專案根目錄啟動伺服器：
    ```bash
    python3 -m http.server 9000
    ```
  - 部分腳本包含本機特定絕對路徑（如 `/home/hsu/...`），若需執行請依本機環境調整。
